POSTMAN

==================================================
1. REGISTRAR USUARIO ADMIN
==================================================

Metodo:
POST

URL:
http://localhost:8099/auth/register

Body:

{
  "username": "admin1",
  "password": "admin123",
  "role": "ROLE_ADMIN"
}


==================================================
2. LOGIN
==================================================

Metodo:
POST

URL:
http://localhost:8099/auth/login

Body:

{
  "username": "admin1",
  "password": "admin123"
}

Copiar el token de la respuesta.


==================================================
3. USAR TOKEN EN POSTMAN
==================================================

En cada peticion protegida:

Authorization -> Type -> Bearer Token

Pegar el token recibido en login.

Otra opcion es ir a Headers y poner:

Key:
Authorization

Value:
Bearer TU_TOKEN

==================================================
PASO A PASO EN SWAGGER
==================================================

1. Abrir el link Swagger del microservicio.
   Ejemplo:
   http://localhost:8082/swagger-ui.html

2. Buscar el controller.
   Ejemplo:
   categoria-controller

3. Abrir el endpoint que se quiere probar.
   Ejemplo:
   POST /api/v1/categorias

4. Presionar:
   Try it out

5. Pegar el body JSON.

6. Presionar:
   Execute

7. Revisar la respuesta abajo.

8. Para endpoints protegidos, usar el boton Authorize si aparece.

9. En Authorize pegar:
   Bearer TU_TOKEN

10. Repetir las pruebas con GET, POST, PUT o DELETE.
